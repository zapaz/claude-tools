# claude-tools

Collection of utilities for Claude Code.

## Tools

- **claude-switch** — Multi-account switcher for Claude Code on macOS. Stores OAuth tokens in macOS Keychain and lets you launch Claude Code with any subscription. Supports unlimited subscriptions with labels (Pro, Max 5x, Team, etc.) and auto-detection. See [CLAUDE-SWITCH.md](CLAUDE-SWITCH.md) for details.

## Versioning

When modifying `scripts/claude-switch`, bump the `VERSION` variable (patch for fixes, minor for features).
