Welcome to **Notable**, a simple Markdown note manager.

## Features

- Create and manage notes with YAML frontmatter
- Tag-based organization
- Full-text search
- HTML export

## Getting Started

Use the CLI to add your first note:

```
notable add --title "My First Note" --content "Hello, world!"
```

Then list your notes with `notable list`.
