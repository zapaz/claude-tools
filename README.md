# claude-tools

Collection of utilities for Claude Code.

## Tools

- **[claude-switch](claude-switch/README.md)** — Multi-account switcher for Claude Code on macOS.
- **[clautty](clautty/README.md)** — Ghostty split launcher for Claude (local + ssh).
- **[statusline-advanced](statusline-advanced/README.md)** — Advanced status line for Claude Code.
